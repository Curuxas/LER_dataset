# LER_dataset
Dataset for "Agricultural diversification spares land for nature"
This repository contains the data used in:
Lopez Rodriguez, Susana; le Clech', Solen; Ros, Gerard; van Bussel, Lenny; van Apeldoorn, Dirk; Alkemade, Rob. 2026, Nature Communications.

## Files
LER_dataset: dataset obtained from literature review and used for the analyses presented in the above-mentioned study 
## Description
Dataset includes a first sheet describing the headers in each column of the database. Diversified agricultural systems are separated in sheets. The dataset contains: general information about each experiment, productivity data in control simplified systems and treatment diversified systems, calculations of partial and total land equivalent ratios (LER), information about use of inputs and notes. In each experiment (row), units are the same in treatment and control, and the result (LER) is unitless. A first order meta-analysis for LER was carried out with primary studies for each diversified agricultural system, assessing the influence of use of inputs on LER and variability per world region. A second order meta-analysis integrated the results of the first order meta-analysis with published meta-analyses.
